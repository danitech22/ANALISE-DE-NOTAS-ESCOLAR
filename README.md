# 📚 Sistema de Análise de Notas Escolares

Este projeto é um programa em Python que realiza a **análise de notas escolares** a partir de registros de desempenho dos alunos ao longo dos bimestres.

O sistema processa os dados e gera indicadores acadêmicos, exibindo os resultados de forma clara diretamente no terminal.

---

## ⚙️ Funcionalidades

- Calcula o **total de notas por aluno**
- Identifica o **aluno com maior soma de notas**
- Calcula o **total de notas por bimestre**
- Identifica o **bimestre com maior desempenho geral**
- Classifica os alunos de acordo com o desempenho total:
  - 🟥 Baixo
  - 🟨 Médio
  - 🟩 Excelente

---
